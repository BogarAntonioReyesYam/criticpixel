# PixelVerdict - Game Review SPA (Instant-Gaming Aesthetic)

PixelVerdict es una plataforma moderna de reseñas de videojuegos diseñada con una estética de alta densidad y contraste, optimizada para ofrecer una experiencia visual impactante y fluida.

## 🚀 Características
- **Diseño Instant-Gaming**: Interfaz oscura con acentos naranjas vibrantes.
- **Navegación Fluida**: Implementada con React Router para una experiencia SPA (Single Page Application).
- **Ordenamiento Inteligente**: Filtros por puntaje y orden alfabético en tiempo real.
- **Responsive Design**: Totalmente adaptado para móviles, tablets y desktops.
- **Arquitectura Limpia**: Separación clara entre componentes, vistas y datos.

## 🛠️ Tecnologías
- **React 19**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (Iconografía)
- **React Router 7**

## 📦 Instalación y Uso

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TU_USUARIO/criticpixel.git
   cd criticpixel
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar en desarrollo:**
   ```bash
   npm run dev
   ```
   La aplicación estará disponible en `http://localhost:5173/`.

4. **Construir para producción:**
   ```bash
   npm run build
   ```

## 📁 Estructura del Proyecto
- `src/components`: Componentes de UI reutilizables.
- `src/views`: Páginas principales (Home, Detalles).
- `src/data`: Mock data de los juegos.
- `src/App.jsx`: Configuración de rutas.
- `tailwind.config.js`: Tokens de diseño personalizados.
